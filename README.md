# Number Guessing Game

## About the Project

This is a simple console-based Number Guessing Game developed using Java as part of the OASIS INFOBYTE Java Development Internship.

The program generates a random number between 1 and 100. The player has seven attempts to guess the number. After each guess, the program provides a hint indicating whether the guess is too high or too low. The player can also choose to play another round after the game ends.

## Features

- Generates a random number between 1 and 100.
- Provides hints after each incorrect guess.
- Limits the player to seven attempts per round.
- Displays the correct number if the player cannot guess it.
- Allows the player to restart the game.
- Handles invalid input.

## Technologies Used

- Java
- Java Scanner class for user input
- Java Random class for number generation
- Eclipse IDE

## How to Run

1. Install JDK 21 or another compatible Java version.
2. Clone or download this repository.
3. Open the project in Eclipse or another Java IDE.
4. Make sure `NumberGuessingGame.java` is in the `byted` package, as specified in the source file.
5. Run `NumberGuessingGame.java` as a Java application.
6. Enter your guesses in the console.

## How to Play

1. Run the program.
2. Enter a number between 1 and 100.
3. Follow the hints displayed after each guess.
4. Try to guess the number within seven attempts.
5. Enter `yes` to play another round or `no` to exit.
